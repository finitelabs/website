About

Finite Labs builds Control4 drivers. We sell them on DriverCentral, publish most of them on GitHub, and keep them updated as devices and Control4 change.

We also take on custom driver and software work.

Our Founder

Derek Miller is a software engineer and the founder of Finite Labs. He builds and supports our drivers.

Connect with Derek on LinkedIn.

How We Work

  • Local control wherever the device allows it
  • Drivers that behave like Control4's own lights, locks and thermostats
  • Source code on GitHub for most drivers and the libraries behind them

Our Drivers

Universal Zigbee 3.0

One driver for thousands of Zigbee 3.0 devices from hundreds of brands. Devices join the controller's own Zigbee network, with no hub or bridge. Requires Control4 OS 4.3 or later.

View on DriverCentral

ESPHome

Connects Control4 directly to ESPHome devices on the local network, to control their lights, switches and sensors.

View on DriverCentral

TP-Link Kasa and Tapo

Local control of TP-Link Kasa and Tapo plugs, power strips and lights, with no TP-Link cloud. Devices keep working after TP-Link firmware updates.

View on GitHub

Home Connect for Apple Home

Brings Control4 devices into Apple Home and Siri through a Homebridge or HOOBS server on the local network.

View on DriverCentral

MQTT

Connects Control4 to any MQTT broker, so devices that use MQTT can show up as relays, contact sensors, buttons and variables.

View on DriverCentral

InfluxDB

Logs Control4 variable changes to an InfluxDB database, with batched writes and buffering while the database is offline.

View on GitHub

Finite Labs Essentials

Standalone utility drivers that add aggregated sensors, virtual devices, variable expressions and network requests to Control4 programming.

View on GitHub

Hatch

Controls the sound machine and night light on Hatch Rest+ and Restore devices from Control4.

View on GitHub

Nuheat

Brings Nuheat Signature and Conductor floor heating thermostats into Control4 as native thermostats, with setpoint, mode and hold control.

View on GitHub

Schluter DITRA-HEAT

Brings Schluter DITRA-HEAT-E-WiFi floor heating thermostats into Control4 as native thermostats, with setpoint, mode and schedule control.

View on GitHub

Open Source

Most of our drivers are free on GitHub, along with the Lua libraries they use. Our DriverCentral editions are encrypted with the Lua window locked, and come with direct support from Derek.
